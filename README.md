# 단어쏙 (VocaSsok) 목업

정재훈의 2026년 10월 12~15일 샘플 단어 39개로 체험하는 초중등 영어 단어 복습입니다. 기존 폴더는 비어 있어 원본 목업이나 음원 URL을 확보하지 못했습니다.

학습자 화면은 한 라운드 최대 5개로 구성합니다. 전체 선택 시 8라운드(마지막 4개)이며 라운드마다 멈춰 다음 라운드 또는 쉬기를 선택합니다. 오답 재확인은 같은 라운드 안에서 진행합니다. 보류 단어는 다시 시도할 수 있고 다음 라운드로 넘어가도 미완료로 남습니다. 마지막에 이전 라운드의 남은 단어로 돌아갈 수 있습니다. 화면에는 현재 라운드의 남은 개수와 진행률만 표시하고, 상세 분류와 원래 퀴즈 결과는 저장·내보내기 데이터에 유지합니다.

읽기 화면은 큰 마이크 버튼 하나를 중심으로 구성합니다. 연결 중 → 듣는 중(색상·파동 표시) → 실시간 인식 텍스트 → 최종 결과 순으로 표시합니다. 인식 중 다시 누르면 입력을 마치고 결과를 기다립니다. 최종 일치 시 실제 인식 텍스트를 뜻 선택 화면에 표시합니다. 상시 듣기·자가 확인·보류 버튼은 제거했습니다. 인식 실패 시 시범은 자동 재생하며, 미지원·권한 오류·반복 실패 때에만 ‘마이크 없이 연습하기’를 표시하고 자가 확인으로 기록합니다. 중간 인식 텍스트의 도착 속도는 브라우저의 인식 서비스에 따라 달라집니다.

## 웹 테스트

GitHub Pages: https://hyunqwer.github.io/vocaSsok/

Chrome에서 HTTPS 주소를 열고 마이크를 허용해 테스트합니다. 웹 버전도 복습 기록은 브라우저 로컬 저장이며 서버 저장·윤선생 자동 연동은 없습니다. 로컬 실행과 웹 버전은 서로 다른 저장소를 사용합니다.

## 실행

이 폴더에서 `python -m http.server 8765 --bind 127.0.0.1`을 실행하고 브라우저에서 http://127.0.0.1:8765/vocabulary_activity.html 을 여세요. Chrome 또는 Edge에서 마이크를 연결하고 ‘읽기 확인’을 누르면 권한을 요청합니다. 파일을 직접 열 수도 있지만 음성인식과 로컬 저장 지원은 브라우저에 따라 다릅니다.

음성인식 API 감지는 서비스 성공을 보장하지 않습니다. 권한 거부, 마이크 없음, 네트워크 오류, 무응답은 화면에 따로 안내합니다. 실제 사람의 음성 인식과 마이크 권한은 사용자 환경에서 확인해야 합니다. 음성인식 서비스는 브라우저 제공업체로 소리를 전송할 수 있습니다.

## 체험 범위

- 읽기 확인 → 한국어 뜻 4지선다 → 정답 확인 → 다음 단어
- 음성인식 실패 시 합성음성 시범 제공, 재시도 또는 보류
- 미지원 환경에서 읽기 자가 확인 제공; 독립 통과로 집계하지 않음
- 도움받은 읽기와 뜻 오답은 다른 단어 3개 후 해당 항목 재확인. 남은 단어가 적으면 가능한 단어를 먼저 진행
- 날짜별 선택, 보류 재시도, 진행 중 복습 이어하기, JSON 기록 내보내기
- 시간은 보너스이며 인식·합성음성·비활성 탭 대기 제외

## 저장 및 기본 정책

브라우저 localStorage의 `vocassok.review.v1`에 진행 상태와 완료 이력을 저장합니다. 저장 차단 시 임시 메모리라는 안내를 표시합니다. 같은 기기라도 브라우저·주소·포트가 달라지면 별도 저장소입니다. JSON 내보내기는 백업용이며 가져오기는 미구현입니다. 새 복습 시작은 진행 중 상태를 교체하고 완료 이력은 유지합니다.

읽기 첫 인식 정오, 음원 도움, 재시도, 자가 확인, 독립 통과와 뜻 첫 선택 정오, 재시도, 지연 재출제 통과를 별도 기록합니다. 완료 이력에 활동일, 마지막 독립 통과일, 다음 예정일을 기록합니다. 다음 예정일은 시범 규칙으로 독립 통과 3일 후, 도움·자가 확인 완료 1일 후입니다. 장기 기억을 판정하지 않습니다.

원래 퀴즈 결과는 단어 데이터의 `originalQuiz`에 별도 보관합니다. arrive만 ‘출발하다’로 오답이며 다른 38개는 정답입니다. 기존 뜻 표기는 수정하지 않았습니다.

서버 저장, 실시간 윤선생 연동, 원본 원어민 음원은 구현하지 않았습니다. 현재 소리는 브라우저 합성음성입니다. AI 튜터(읽기 지도 → 뜻 말하기 → 본문 문장 읽기·해석)와 독립 통과 단어의 뜻 말하기 도전은 후속 모듈이며 현재 화면에 포함하지 않습니다.

## 모바일 화면

뜻 퀴즈가 나타날 때 영어 단어를 합성음성으로 한 번 재생하고, 뜻을 틀리게 고를 때마다 한 번 더 재생합니다. 이 재생은 읽기 확인 이후의 복습이므로 읽기 도움 여부나 독립 통과 기록을 변경하지 않습니다. 재생 중 오답을 다시 선택하면 이전 소리를 중단하고 다시 재생하여 소리가 겹치지 않게 합니다. 다음 단어로 이동할 때 이전 소리를 중단합니다.

사용 가능한 화면 높이(svh)에 맞춰 헤더·학습 카드·하단을 배치하고 선택지는 2×2로 표시합니다. 320×568 및 390×664 브라우저 뷰포트에서 시작·읽기·긴 구문 뜻 선택 화면의 페이지 넘침을 확인했습니다. 글자 확대나 매우 낮은 가로 화면에서는 내용 접근을 위해 스크롤을 허용합니다. 실제 기기의 주소창·안전 영역·마이크 권한창은 추가 확인이 필요합니다. 정답은 350ms 표시 후 자동으로 다음 단어로 넘어가고, 오답은 다시 선택합니다. 빠른 중복 탭은 한 번만 기록합니다.
